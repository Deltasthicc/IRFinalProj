# RAG study: human ratings

Rated by shash, each blind to which system wrote an answer (the order of the three answers was shuffled per question; closed-book answers can still be recognised because they carry no citations). Reference answers were written by the rater from the filings before rating. Generated by `eval/human_score.py` from `eval/out/rag_scores_human.json`; do not edit the numbers by hand.

## Citation precision and number grounding

Citation precision is the share of cited passages that the rater judged to support the sentence they are cited for (with several raters, a citation counts only if all agree). Number grounding is automatic (the verifier) and does not depend on the rater.
